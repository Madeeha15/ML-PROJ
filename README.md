# Student Placement Prediction & Analytics

## Abstract

A Machine Learning based system that predicts student placement using academic performance, internships, projects, aptitude and communication skills.

## Algorithms

* Logistic Regression
* Decision Tree
* Random Forest

## Features

* Placement analytics dashboard
* Model comparison
* Accuracy, Precision, Recall and F1-score
* Confusion Matrix
* Student placement prediction

## Technologies

Python, Streamlit, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

## Run Project

```bash
py -m pip install -r requirements.txt
py -m streamlit run app.py
```
